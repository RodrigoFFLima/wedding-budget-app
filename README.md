# Wedding Budget App

Este projeto tem como objetivo criar uma aplicação para controle de gastos do casamento. O app será compartilhado entre o casal e a cerimonialista, permitindo que todos acompanhem os gastos de fornecedores, orçamento total e muito mais.



## Estrutura do Projeto

O projeto está dividido em três partes principais:

#### 1. Frontend (Web)
* Localizado na pasta web/.
* Construído com React + TypeScript e Tailwind CSS.
* Usando o Vite para build e desenvolvimento.

#### 2. Backend (API)
* Localizado na pasta backend/.
* Será construído com .NET e utilizado para persistir dados (como gastos, fornecedores, etc.).

#### 3. Mobile (App)
* Localizado na pasta mobile/.
* O aplicativo será desenvolvido com React Native para Android e, futuramente, iOS.



## Instalação

#### 1. Backend (.NET)
- Instruções de como rodar o backend serão adicionadas quando a API for configurada.

#### 2. Frontend (Web)

- Navegue até a pasta web/:

```bash
cd web
```

- Instale as dependências:

```bash
npm install
```

- Rode o projeto::

```bash
npm run dev
```

#### 3. Mobile (App)

- As instruções de como rodar o aplicativo no Android serão adicionadas quando o desenvolvimento iniciar.

## Tecnologias Usadas
 - Frontend: React, TypeScript, Tailwind CSS, Vite.

 - Backend: .NET (API Restful).

 - Mobile: React Native.
